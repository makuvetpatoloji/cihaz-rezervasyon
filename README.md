# Patoloji Cihaz Rezervasyonu

- Uygulama: https://makuvetpatoloji.github.io/cihaz-rezervasyon/
- Bu depoda yalnızca telefon/bilgisayar arayüzü bulunur. Rezervasyon kayıtları Google E-Tablo'da tutulur ve Google Apps Script üzerinden okunup yazılır.
